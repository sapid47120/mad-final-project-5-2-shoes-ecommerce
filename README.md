# shoes_ecommerce_app

Shoes E-Commerce Website – MAD Final Project

This project is a fully functional Shoes E-Commerce Website developed as part of my Mobile Application Development (MAD) Final Project. The goal of this project was to design and develop a complete online shopping experience with a clean UI, structured layout, and smooth user flow—from browsing products to completing an order.

The website allows users to explore a collection of shoes, view product details, add items to the cart, and proceed to checkout. It also includes order confirmation logic and dynamic updates using organized data structures. The project focuses on providing a modern, responsive interface while keeping the codebase clean, readable, and beginner-friendly.

Key Features

Modern product display with images, prices, and categories
Product description and dedicated detail pages
Add-to-cart functionality with real-time updates
Checkout form including:
Customer name
Phone number
Address
Payment method
Order confirmation screen summarizing purchase details
Responsive layout suitable for different screen sizes
Well-structured folder architecture for scalability and readability

Technologies Used
HTML, CSS, JavaScript
Responsive Web Design
Modular code structure

Purpose of the Project

This project helped me strengthen my skills in front-end development, UI layout design, and implementing real-world e-commerce logic. It also improved my understanding of user experience, website structure, and clean coding practices.
